# 🖧 HCIA (Huawei Certified ICT Associate) Course

## 📌 Overview
This repository documents my learning journey in the HCIA (Huawei Certified ICT Associate) course, which provides a strong foundation in computer networking and ICT fundamentals.

---

## 🎯 Course Objectives
- Understand basic and advanced networking concepts  
- Learn OSI and TCP/IP models in detail  
- Configure and troubleshoot small-scale networks  
- Gain hands-on experience with network simulation tools  

---

## 📚 Topics Covered
- Introduction to Computer Networks  
- OSI & TCP/IP Models  
- IP Addressing & Subnetting  
- Routing & Switching Fundamentals  
- VLANs and Network Segmentation  
- Basic Network Security Concepts  
- Network Troubleshooting Basics  

---

## 🛠️ Tools & Technologies
- Huawei eNSP / Network Simulators  
- Packet Tracer (for practice)  
- Basic CLI configuration  
- Networking protocols (TCP/IP, DNS, DHCP)

---

## 💡 Key Skills Gained
- Network design and configuration  
- Understanding of enterprise network structure  
- Problem-solving in network environments  
- Hands-on troubleshooting experience  

---

## 📌 Purpose
This course helped me build a solid foundation in networking and prepare for advanced certifications and real-world networking roles.
